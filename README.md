# SDK Tools

## Introduction
This project contains scripts and utilities that assist with local development tools

## SKDMAN

### SDKJ

`sdkj.sh` provides for a simplified mechanism for using sdkman with java.

`~/sdkjk.sh install 25` will install the latest version of the Temurin distribution that starts with 25
`~/sdkjk.sh install 25 graal` will install the latest version of GraalVM that starts with 25
